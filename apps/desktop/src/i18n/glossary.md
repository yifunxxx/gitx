# gitx i18n glossary

Git core terms stay in English in zh-CN UI to match IDEA / CLI mental model:

Commit, Push, Pull, Fetch, Merge, Rebase, Cherry-pick, Stash, Shelve, Changelist,
Amend, Reword, Squash, Fixup, Worktree, Tag, Remote, Upstream, HEAD, Diff, Stage,
Unstage, Rollback, Checkout, Branch.

Descriptive chrome may be Chinese, e.g. 「Push 3 个 commit 到 origin/main」.
