# 重写编辑弹窗与异步操作保护

日期：2026-11-10。QA-015；原目标继续进行。

## 发现与范围

独立分支的修改说明、压缩、重置、交互变基弹窗缺少仓库身份、重复执行、取消和失败处理。修改说明仅从 Log 已加载详情或标题初始化，未加载正文时可能提交不完整的说明；Reset 不等待预览成功。合并和变基入口也有同类缺口，本轮一并处理。

重写 store 在脏工作区提示后读取可变的仓库和参数进行重试；操作完成后的刷新、冲突提示和 Undo 回调也可能作用于新仓库。`return handleResult(...)` 未等待刷新就释放 busy；刷新异常还会把已完成的 Git 写操作显示成可重试的失败。

独立分支弹窗基线 18 项失败并报告 3 个未处理异常，store 新增基线 18 项失败。它们覆盖行为约定和缺陷路径，不能解读为 36 个独立缺陷。日志：`rewrite-dialog-baseline.log`、`rewrite-store-baseline.log`。

## 修改

- 六个编辑入口共用生命周期保护。导航发起、同路径重开、仓库身份变更或卸载后旧请求失效；始终按自己的弹窗 ID 关闭，不能关闭替代窗口。
- 重写产生冲突窗口时，只关闭已完成的父编辑弹窗，保留冲突窗口。取消脏工作区处理时保留父窗口的编辑内容。
- 执行期间禁止重复提交、编辑和 Escape 关闭；失败显示原因并保留输入；加载失败可重试。加载成功前不能执行 Reset、Reword、Merge 或 Rebase。
- 修改说明主动获取标题和正文，保留用户编辑的完整空白与段落。压缩提交列表、Reset 目标和交互计划来源固定；Reset 执行预览解析后的提交，切换模式清除 Hard 确认。
- 保留集成目录的 root/onto/rebase-merges/autosquash 参数和原生排序限制，交互计划加载失败可重试。
- store 固定原仓库和重试参数，对每一步异步后续工作检查来源；busy 持续到刷新结束，过期 Undo 不执行。冲突窗口不重复打开。
- 已成功写入后的刷新失败单独提示“操作已完成，但界面刷新失败”，不再让编辑窗口诱导重复重写。已经发送给后端的单次操作不会因为前端导航而自动回滚。
- 只同步本轮相关组件、生命周期逻辑、测试及词条；集成目录的 Undo 后端协议等独立改动保留。没有将整个 store、locale 或 Rust 文件覆盖到另一目录。
