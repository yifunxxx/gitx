# QA115 搜索与替换

## 请求与基线

用户优先要求全局搜索支持大小写、全词、正则，不再跳过大文件，同时增加文件内查找、全局/文件内替换，并补教程 Pages 和快捷键设置。开始前读取台账，fetch首次SSL失败后重试成功，master与交付分支检查通过：基线d30880c包含masterfdc5156（0.1.49）。QA114的Log树形修复已命名stash保留，本功能独立交付。

## 实现

- 全局内容搜索通过独立后台扫描和磁盘临时结果存储，按200条分页传输；移除旧5MiB单文件、100MiB总读取、500结果和15秒截断，包含同一行每处匹配、UTF-16列号和高亮片段。
- 大小写、全词、正则、包含/排除glob、隐藏/忽略范围；取消、换词、换项目和迟到分页隔离。取消回收会话，扫描状态显示于任务队列。
- 全局替换逐条预览、按文件勾选/排除（跨页生效），完成搜索及处理草稿后确认写入；冲突编辑器打开或冲突写入未结束时禁止批量替换。所选全部文件先进行SHA-256预检，逐文件再次校验并从同目录临时文件发布；保留换行、BOM和权限。错误明确报告已完成数量并停止后续写入，保留草稿，关闭已变更文件的干净旧缓冲区。输出使用缓冲写入，避免大文件每行两次磁盘写调用。
- File文本读取/保存取消5MiB上限；打开大搜索命中及保存大文本时省略可选HEAD行差异计算。
- 文件、只读差异和冲突面板使用CodeMirror搜索扩展；只读面板只能查找。编辑面板提供当前/全部替换、草稿和撤销。复用样式模块，避免打开关闭编辑器时新增永久样式。
- 动作注册新增全局替换、文件内查找/替换、上一处/下一处、当前/全部替换；Keymap改绑与禁用从编辑内容和查找栏生效。中英文Pages搜索/文件/设置说明及自动生成的功能/快捷键索引同步。
