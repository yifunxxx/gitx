# QA-063 操作队列与等待反馈

来源：用户要求 checkout 等动作有等待反馈，左下角显示正在执行的操作。

开始前 fetch 成功，HEAD 52261a9 包含 origin/master efc2a8a 和最新交付分支。

## 修改

- 后端公共调用边界只跟踪显式用户操作：项目打开、Git 初始化、分支/标签/远程配置、暂存/提交、冲突/历史改写、Stash/Shelf、补丁、工作树、Fork/子模块和手动索引重建。
- 后台 status/refs/log、设置持久化与轮询不登记；已有完整任务生命周期的 Fetch/Pull/Push/Update、原生 Clone/statusProbe 不重复登记。
- checkout 和手动回滚在 store 内登记，覆盖 Git 操作和后续刷新，拒绝重复点击；异常、业务失败、导航离开后都释放任务。顶部显示检出目标及旋转提示。
- 左下角直接显示任务名，同时执行时显示数量，悬停可看完整目标/路径；队列可展开查看全部任务。未提供后端取消能力的任务不显示取消按钮。
- 观察器按 Pinia 实例归属并在 store 销毁时释放。任务结束只表示调用结束，不把结构化失败标记成成功。短操作及时结束，不增加人为等待。
