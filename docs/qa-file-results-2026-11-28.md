## 现象与修改

File菜单已经发起复制、移动等磁盘操作后，切换项目不会取消该操作，但旧实现直接丢弃成功、部分成功及错误通知。同路径重新打开也相同。在原项目中，通知还要等待文件树刷新；刷新期间切换项目同样丢失反馈。QA106此前故意抑制过期提示以避免误关联新项目，本项改为明确显示来源，继续保留旧结果不得更新新树/编辑器的保护。

现在磁盘接口返回时立即通知操作名称、源目录、完成/失败数量及失败路径，失败通知保持到手动关闭。数量按所选顶层条目计算，目录内容不逐个计数。当前项目的编辑器仍在释放保存锁之前更新；导航后只发布源目录通知，不刷新或打开新项目的文件。销毁store后仍不发布通知，等待确认时导航失效仍不执行写入。

任务覆盖的范围保持磁盘操作、目录刷新及新建文件打开；队列和File面板按阶段显示“正在刷新文件视图”“正在打开新建文件”，不在磁盘已经完成后继续显示复制/创建。异常收尾独立说明界面更新失败，避免把已收到的磁盘结果误报成需要重新执行的文件操作。普通目录读取失败本来就由树内错误状态承接，本项没有把它重新认定为写入故障。

没有新增后端取消、重试或队列机制，没有修改Rust文件操作语义。中英文文件教程同步说明结果、计数、任务阶段及导航行为；没有新增快捷键。
