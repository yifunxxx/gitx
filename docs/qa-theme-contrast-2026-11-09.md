# 主题文字与提交图可读性复验

日期：2026-11-09。Windows 桌面调试版，1280×800。

## 修改

原有辅助文字在选中提交的蓝色背景上对比度偏低：浅色为 3.165:1，深色为
3.275:1。文件状态和提交线还共用浅色配色，使部分颜色在深色主题中不易辨认。

调整两套主题的辅助文字、成功/警告/错误文字、文件状态、焦点轮廓和提交线颜色。
保留原有选中背景，补齐深色状态与提交线的独立配色。原生控件通过 color-scheme
跟随主题。选中提交的作者和日期对比度分别提高到 4.976:1、4.912:1。

## 验证

- 独立诊断脚本检查实际 CSS 变量，按透明度合成背景，覆盖内容区和文件侧栏的普通、
  悬停、选中状态，以及卡片、弹出层、工具栏背景。
- 检查的 358 个颜色组合中，原有 217 个低于本轮目标；修改后全部通过。
  文字目标为 4.5:1，图线/焦点轮廓目标为 3:1；实测最低分别为 4.557:1、3.068:1。
  两个工作区的最终颜色结果一致。证据：theme-contrast-before.json、
  theme-contrast-after.json、theme-contrast-isolated.json。
- 集成工作区类型检查与生产构建通过（build-theme-contrast-final.log）；既有主
  JavaScript chunk 约 967 KB 的体积提示仍存在。没有为颜色常量增加实现镜像测试。
- 223 个真实提交的专用仓库包含六父合并、交叉合并与独立历史。桌面实际检查浅/深
  两套主题中的选中提交、作者日期、图线和文件状态；选中合并后详情正确列出六个父提交。
  普通与选中 added.txt 的绿色文件名可辨识，修改、删除、重命名及未跟踪文件也有相应状态色。
- 图布局及 Log 既有回归 17 项通过（complex-log-ui-regressions.log）。独立 Git 核对
  HEAD、refs、index、status 均保持，提交总数及六父关系正确（complex-log-ui-verified.json）。

桌面证据：complex-log-dark-selected-ui.txt、complex-log-light-selected-ui.txt、
contrast-light-file-selection-ui.txt、contrast-dark-file-selection-ui.txt。
截图已在本轮桌面操作中观察；文本证据用于核对界面内容，不单独证明像素颜色。

本轮是上述颜色变量和具体桌面场景的检查，不是整套应用的无障碍认证；所有边框、
占位提示、禁用状态、叠层及第三方控件尚未逐一覆盖。复杂图的整体交互继续验收。
