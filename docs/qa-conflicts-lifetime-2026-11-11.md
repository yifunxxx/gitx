# 冲突列表的异步操作保护（QA-017）

## 发现与修复

独立分支双击文件会立即关闭冲突列表，按钮打开合并页则在等待后关闭当前最上层弹窗；两者都没有完整的失败、取消与来源保护。集成目录已有部分改进，但仍会把跳过的打开/继续结果当成功，同路径重开和仓库身份变化也不能使旧请求失效。

受控异步基线共 32 项：独立分支 30 项失败、2 项通过；集成目录 26 项失败、6 项通过。失败项包含旧行为缺失的新交互与结果契约，不代表发现了同等数量的独立缺陷。

- 冲突列表固定原弹窗 ID 与仓库会话。关闭、替换、被子弹窗覆盖、导航、身份变化或组件卸载后，旧打开请求不会创建编辑器或关闭其他窗口；被覆盖后再出现也不会复活旧请求。
- 编辑器打开返回明确的成功/跳过结果，重复点击只发起一次加载；已经打开的标签可直接激活。原弹窗只在确实打开成功后关闭。二进制和 gitlink/symlink 不进入文本编辑器。
- 初始加载同时等待冲突列表与 Git 操作状态。失败显示原因和“重试加载”，不显示“全部解决”或允许写入。加载编辑器失败保留选择与窗口，可再次尝试；只读加载可以按 Escape 或“关闭”取消。
- 接受己方/对方只处理选中文件，不再在无选择时退化为接受全部。补齐单击、Ctrl/Shift 选择、已删除的连选锚点、Enter/空格和复选框事件隔离；修饰键、长按和输入法事件不误触发。
- 接受一侧、自动解决和保存结果固定原仓库，复制选中路径，并保持每个路径的写入锁直到请求完成；离开后返回也不能重复写入。旧会话完成后不修改新会话、不发起新仓库刷新。
- 写入使尚未完成的编辑器读取失效；成功接受一侧关闭相应编辑器，自动解决后关闭已解决的标签。后续刷新集中检查原会话；刷新失败明确提示“操作已完成”，阻止直接重复写入，允许重新加载。
- 继续合并/变基等待真实结果。失败、跳过或仍有冲突时保留窗口和错误；确认完成后只关闭原弹窗。正在完成的重写操作仍允许新冲突窗口读取数据，不会卡在空白加载态。
- 同步到集成目录时保留其独立的合并结果标记检查和已有测试；主分支提取相关中文/英文标签。没有更改 Git 合并算法。
