## 问题与修改

File复制、移动和删除在目标/确认弹窗之前调用topLevelPaths，去掉重复路径及已选父目录下的子项。旧实现对每条路径扫描所有其他选择；512个平铺文件就执行261632次前缀比较，新增复杂度回归失败，其余28项（含显式规模probe）通过。该成本在UI线程同步发生，影响批量操作的准备响应；不据此认定全部滚动延迟的根因。

现只检查路径各分隔符之前的祖先是否存在于当前选择Set，不再对全部路径两两比较。去重后仍保持原输入顺序，父目录晚于子项出现也能正确归并；精确大小写、字面分隔符和相近名称边界不变。不规范化输入、不代替后端路径校验，也不修改后端1000个顶层操作项的限制。
