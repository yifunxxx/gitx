## 复现与修改

FileToolWindow的selectedRows通过遍历全部可见逻辑行，再对每行执行selectedPaths.includes生成批量目标。菜单的禁用状态、F2及拖动都会取该计算值；行高亮和右键/拖动入口也重复includes。大目录全选后会产生行数×选择数的路径比较；这里的selectedRows是按需要计算，并非每个滚动帧都会遍历整树。

在真实FileToolWindow/VirtualList中使用512个已选文件，实际打开右键菜单并复制相对路径；对选择数组的索引读取计数为232922，新增复杂度回归旧实现失败，原15项交互对照通过。该回归同时核对输出顺序和选择保持，采用宽松的线性读取上限而非机器耗时阈值。

修复用当前selectedPaths的computed Set共享成员索引，供可见行高亮、右键/拖动入口及selectedRows使用；批量目标仍按当前文件树顺序生成，移除的行不会进入操作。空选择直接返回空数组。索引跟随选择整体替换和数组内部变更，不维护全局或历次选择缓存；组件卸载或选择替换后旧Set可释放，本次未测长期堆泄漏。
