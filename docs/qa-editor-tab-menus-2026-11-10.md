# 编辑器标签关闭菜单

日期：2026-11-10。对应台账 QA-001、QA-011。

## 发现与修改

用户截图中的 Diff 标签只有关闭按钮，没有右键菜单。六类编辑器原先各自渲染标签，并分别调用 store 关闭方法，批量操作没有统一的可见顺序。

统一标签按钮增加“关闭当前、关闭其他、关闭右侧、关闭全部”。适用于 Diff、文件历史、引用比较、历史仓库、合并和文件查看器。菜单基于被右键的标签；右键后台标签不会切换当前文档。“关闭右侧”使用实际显示顺序，跨编辑器类型生效。Workspace 始终保留，无目标的动作禁用。关闭当前标签后选中相邻存活标签；关闭后台标签保留当前视图；关闭其他保留并激活菜单目标。

菜单使用已有 Reka 依赖的定位和键盘行为，提供 Shift+F10/菜单键入口，禁用项、方向键、Enter、Esc 和焦点恢复。完整标题保留在悬停提示中。关闭后的焦点恢复不覆盖新弹出的确认对话框或已经获得焦点的存活标签。

实现时发现原关闭路径会直接移除合并编辑器中的未应用编辑。现在记录每个合并标签的初始结果，编辑后关闭需确认；撤销到初始内容不提示。取消会保留整批目标；重复请求不会产生多个确认；仓库导航（含 A→B→A）废弃等待中的关闭。等待期间新开的标签不会进入原批次。初始内容记录随关闭和仓库切换清理。
