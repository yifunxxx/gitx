- 切换编辑标签、隐藏/卸载 File 后，旧组件回调可能提示错误、滚动或抢焦点，且新目标被旧 busy 阻塞。现在在项目、导航、编辑目标及可见性变化时立即释放本次定位状态；旧 finally 不能清除新请求的状态。手动树选择、键盘导航、右键和过滤输入取消旧定位。
- 过滤只匹配行名称，旧实现却依据完整路径决定是否清除过滤；过滤 `src` 时定位 `src/target.ts` 失败。现在先找到真实目标，再根据实际过滤结果决定是否清除；匹配目标的过滤保留，找不到文件或取消时不清除过滤。
- 定位共享仍在执行的根/目录读取，支持失败后再次点击重试，保留已有缓存；新旧定位共用父目录请求时只有新目标被选中。
- 定位等待显示加载图标。成功后恢复树键盘焦点；如果用户已经转入其他字段，不抢回焦点。浏览器因按钮禁用产生的 blur 单独覆盖。
