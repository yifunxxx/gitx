# QA-090：消失目录的缓存与读取生命周期

日期：2026-11-25。类型：已复现的展开等待缺陷。基线60b6957已包含最新master5241dd5（0.1.47）；开始前成功fetch并核对主分支和交付分支。全程主线程。

## 现象与修复

File树某目录正在读取时，父目录刷新发现它已被删除或替换为文件。旧实现只清除展开状态，仍在`directories`与`pending`里保留该路径；同名目录随后重新出现，用户展开时会等待旧目录的请求，直到旧请求完成才读取新目录。祖先目录消失时，其后代也有相同问题。此问题可在慢磁盘/共享路径或外部目录替换中影响响应，但本轮未证明它是用户历史整体卡顿的根因。

父目录成功读取后，现在按目录边界清除失效子树的缓存与请求占位。旧响应受原有目录对象身份检查约束，不能写入重建目录，也不能清掉新请求的loading/pending；同前缀的兄弟目录与仍存在的折叠目录保持原有复用。已经发出的后端读取仍会结束，本项没有新增后端取消API。

代码也不再长期保留已经消失的子树缓存，但没有以此声称测得原生堆泄漏或给出内存改善百分比。仅修改File树store，不修改Git写入、编辑器保存或用户安装程序。
