# 搜索与替换

| 需求 | Windows / Linux 默认入口 | 范围 |
| --- | --- | --- |
| 按文件名跳转 | `Ctrl+P` | 当前工作区，支持模糊路径 |
| 全局内容搜索 | `Ctrl+Shift+R` | 磁盘上的 UTF-8 文本 |
| 全局替换 | `Ctrl+Shift+H` | 搜索结果中的已选文件 |
| 文件内查找 | `Ctrl+F` / 编辑器顶部查找栏 | 当前编辑器，包括未保存草稿 |
| 文件内替换 | `Ctrl+H` / 查找栏展开替换 | 可编辑文件或冲突结果 |
| 下一个 / 上一个匹配 | `F3` / `Shift+F3` | 当前编辑器 |

macOS 使用 Cmd；文件内替换为 `Cmd+Option+F`。以上动作及「替换当前匹配」「替换文件内全部匹配」均可在 **Settings → Keymap** 搜索并改绑；完整默认值见[快捷键](./shortcuts)。

## 全局搜索

1. 打开项目或普通文件夹，按 `Ctrl+Shift+R`。
2. 输入文字；查找框内 **Aa** 区分大小写、**.\*** 正则表达式、**W** 全词匹配。关闭正则时按字面文本搜索。
3. 需要限定范围时填写包含/排除模式，以逗号分隔，例如 `src/**, *.vue` 和 `dist/**, *.lock`。`**` 可跨目录；裸文件名匹配任意深度，目录名包含其子项。
4. 根据需要勾选「包含隐藏文件」「包含忽略文件」。初始值沿用 File 设置，本窗口调整只影响本次搜索。
5. 结果边扫描边显示，每条包含路径、行列号和高亮片段，同一行的每个匹配均列出。每页 200 条，翻页不会重新扫描。点击或在搜索框中按上下方向键、Enter 打开命中。

内容搜索不再限制单文件大小、总读取量、扫描时间或结果条数。扫描在后台逐行读取，结果暂存到磁盘，界面只读取当前页；可随时取消或换词。临时结果需要磁盘空间，内存需求主要取决于最长的一行。换项目/关闭窗口会取消扫描并回收临时结果。任务队列显示正在搜索的进度。

排除模式匹配到目录时，会跳过该目录及其子树，避免遍历依赖或构建产物。例如排除 `node_modules` 会跳过任意深度的同名目录；`build/**` 只作用于工作区根下的 build 范围。包含模式仍会遍历父目录以寻找符合条件的文件，排除优先于包含；勾选隐藏或忽略文件也不会取消显式排除。

点击扫描进度旁的「取消」会停止扫描，收尾后仍可翻页查看已完整扫描文件的结果；尚未完整读取的文件会撤回临时匹配，因此总数可能减少。停止后的结果不能直接替换，请先「重新搜索」并等待完成。更改条件、关闭窗口或切换项目会释放旧结果。

翻页时保留当前页号和内容，显示加载状态并暂时禁用结果打开及翻页按钮；成功后切换到新页。读取失败会保留原页并显示「重试」，重试只读取失败的目标页，不重新扫描。

刷新、停止、翻页或重试导致当前按钮暂时不可用时，焦点会回到搜索框，可以继续输入、用上下方向键选择结果，或按 Esc 关闭。正在批量替换写入时，Esc 不会中断写入；完成后可正常关闭。文件名搜索的停止和重试也保留窗口内的键盘焦点。

全局搜索针对已保存的 UTF-8 文本，不搜索编辑器草稿。二进制、无效编码、读取失败会在可展开提示中列出原因（最多展示前 20 个原因）；符号链接不跟随，Git 元数据目录不搜索。全局正则逐行匹配，支持 Unicode、字符类、分组、重复和捕获，**不支持跨行、回溯引用或前后向断言**；不支持的表达式会显示错误。

LF、CRLF、CR 及混合换行均按编辑器的行列定位，替换保留每处原始换行。空文件和以换行结束的最后一个空行也参与正则搜索，例如 `^$` 可以匹配这些空行。

## 全局替换

1. 按 `Ctrl+Shift+H`，或在搜索窗口上方切换到「替换」。查找和替换输入对齐，标题随模式变化。
2. 填写替换内容（空内容表示删除匹配）。每条结果下方显示此次匹配替换后的片段。正则模式支持 `$1`、`${name}` 捕获组，`$$` 表示美元符号；普通模式按字面写入。
3. 默认选择所有匹配文件，包括其他结果页。底部显示已选文件数；取消任意一行复选框，会排除该文件的全部匹配，同文件其他行同步取消并淡化。
4. 等待扫描完成，保存/关闭未保存文件草稿，并完成或关闭冲突编辑器。点击「替换 N 个文件」，核对数量，再点击「确认替换」。
5. 完成后点「重新搜索」检查结果，并在 Commit 中审阅差异。

批量替换直接写磁盘，不自动提交。执行前校验所选全部文件的内容摘要，搜索后被修改的文件会阻止本次替换并要求重新搜索；每个文件通过同目录临时文件发布，保留换行符、UTF-8 BOM 和文件权限。单文件失败会停止后续写入，并报告已完成的文件数量和错误；整批不是跨文件事务，已完成文件不会自动回滚。需要撤销时使用 Git 差异和回退，非 Git 文件请保留备份。打开的干净文件标签会失效关闭，以免之后保存旧内容；未保存草稿不会被覆盖。

如果写入期间发生项目切换，旧搜索窗口会关闭并请求停止后续替换，任务队列仍保留源项目任务直到结束。完成通知会标明源目录、已完成数量及错误；已经写入的文件不会自动回滚。等待期间暂不允许其他文件操作或保存，避免提前解除写入保护，结束后恢复操作。

## 文件内查找和替换

聚焦编辑器后按 `Ctrl+F`，选中的文字会带入查找框；默认只显示查找行，点左侧小箭头可展开替换行（`Ctrl+H` 也会展开并聚焦替换）。查找框内的 Aa / .* / W 分别控制大小写、正则和全词；右侧上下箭头切换匹配，**Find All** 选中所有匹配。查找与替换输入外框共用列宽，窄面板自动将动作移至下一行；焦点和选项开启状态分别高亮。正则采用 JavaScript 语法，与全局搜索的正则范围有所不同。查找栏位于当前编辑器内容区顶部，不会盖住 Settings 等全局对话框。

可编辑文件和冲突结果展开后提供替换框、「替换」和「全部替换」，后者默认快捷键为 `Ctrl+Alt+Enter`。修改进入当前草稿，可用 `Ctrl+Z` 撤销，普通文件使用 `Ctrl+S` 保存；冲突编辑仍通过冲突界面的保存流程写入。只读 Diff 和冲突来源面板只能搜索，不能替换。Esc 关闭查找栏。

全局 **在文件中查找** 对话框上方显示当前工作区和查找/替换模式；包含/排除使用固定标签，结果按路径、行列号、匹配片段及替换预览排列。窄窗口中范围自动换行，中间区域可滚动，底部始终保留取消和搜索/替换按钮；确认替换前会突出显示文件数量及直接写入磁盘的提示。

## 其他查找入口

`Ctrl+P` 按名称/路径模糊跳转，不需要先展开目录。该名称搜索仍最多显示 500 项，达到扫描限制会提示；这不影响全局**内容**搜索（`Ctrl+Shift+R`）。

File 工具窗顶栏的**定位当前文件**图标（准星）会展开路径、滚动并选中当前活动编辑器或 Diff 对应的文件；没有可定位文件或不在树中时按钮禁用或提示。树顶部 **Filter loaded files** 只过滤已加载节点；Log 筛选用于提交历史；`Ctrl+Shift+A` 用于查找应用动作，见[历史](./history)、[文件](./files)和[工作区](./workspace)。
