# 文件跳转与内容搜索

## 选择合适的入口

| 想找什么 | 使用什么 | 搜索范围 |
| --- | --- | --- |
| 已展开树中的名称 | File 顶部 Filter loaded files | 已加载节点及必要的父目录 |
| 任意目录下的文件 | `Ctrl+P` / Go to File | 整个工作区内符合显示规则的文件 |
| 文件内容中的文字 | `Ctrl+Shift+F` / Find in Files | 磁盘上的 UTF-8 文本 |
| 软件命令 | `Ctrl+Shift+A` / Find Action | 应用动作 |
| 提交说明/作者/分支 | Log 筛选栏 | Git 提交历史，见[历史](./history) |

## 按文件名跳转

1. 打开工作区，按 `Ctrl+P`。
2. 输入文件名或路径的一部分，例如 `app.ts` 或 `src/app`。支持模糊匹配，不需要先展开目录。
3. 查看结果中的路径，区分同名文件。
4. 使用上下方向键选择，Enter 打开；Esc 取消。发生错误时点 Retry。

## 搜索文件内容

1. 先保存希望搜索的编辑器内容，再按 `Ctrl+Shift+F`。
2. 输入需要查找的文字，例如 `Search`。这是**字面文本**搜索，不是正则表达式。
3. 按需要切换大小写匹配，等待结果。
4. 每条结果包含路径、行号、列号和片段。选择后打开文件，并定位到命中位置。

![全局内容搜索与命中位置](/screenshots/search-en.jpg)

同一行只展示第一个匹配；列号按编辑器使用的 UTF-16 位置计算，emoji 可能占两列。已打开文件的未保存草稿会保留；由于搜索的是磁盘，草稿与磁盘不同时应重新核对定位。

## 为什么没有搜到

搜索遵循 File 的隐藏/忽略设置；若需要 `.env.example` 等隐藏文件，到 **Settings → Project Files** 检查显示隐藏选项。二进制、无效 UTF-8、超大或不可读文件会跳过，界面会提示跳过/截断情况。不要把不完整结果当成“整个项目都不存在”。

为避免大目录长时间阻塞，当前搜索最多返回 500 条；扫描上限为 15 秒、100,000 个条目、10,000 个目录、256 层深度。内容搜索单文件最多 5 MiB，总读取最多 100 MiB。遇到限制可缩小打开的工作区、使用更具体关键词，或调整显示规则。

搜索进行时可以取消；换词或切换工作区后，以最新搜索结果为准。非 Git 文件夹也可以使用文件名和内容搜索。
