# 终端、控制台与任务

## 集成终端

点击底部 **Terminal**，或按 `Ctrl+反引号` 切换。先打开文件夹，再用 **+** 新建会话；Windows 可选择 PowerShell 或 Command Prompt。终端是真实 Shell，会对所处目录执行实际命令。

1. 检查会话的 **Started in** 目录。
2. 输入所需命令，按 Enter 执行。
3. 用会话选择器在多个终端之间切换。隐藏面板会保留会话；关闭会话会停止其进程。
4. 需要在指定目录启动时，可从 File 的目录右键 **Open in Terminal**。

最多同时保留 16 个会话。切换项目后，已启动 Shell 的目录不应凭新项目名猜测，执行命令前检查路径。终端输出会保留有限滚动历史，大量输出不是无限日志存储。

| 操作 | 方式 |
| --- | --- |
| 复制选择 | `Ctrl+Shift+C` 或终端右键 Copy |
| 粘贴 | `Ctrl+Shift+V` 或 Paste；先检查将执行的命令 |
| 中断命令 | 没有选中文字时，`Ctrl+C` 传给 Shell；有选择时先复制选择 |
| 全选、清屏 | 右键 Select All / Clear |
| 关闭 | Close terminal and stop its process |

终端输入区按 `Shift+F10` 或菜单键打开右键菜单。会话标签获得焦点后，可用左右方向键切换，Home / End 跳到首尾标签。复制、粘贴和菜单操作不会因长按而重复触发；附加 Alt 等修饰键不会被误当作这些快捷键。

Web 演示后端不提供真实交互终端；使用安装的桌面软件。

## Console

底部 **Console** 用于查看 Git 操作输出、错误和任务消息。它不是交互式 Shell；不能把在 Console 中选中文字当作执行命令。遇到认证、hooks、路径或 Git 返回错误时，先查看与失败操作对应的条目。

复制日志给他人前检查路径、仓库地址和其他个人信息。Console 有保留上限；需要完整长期记录时另行保存必要日志。

## 后台任务队列

点击状态栏 **Background processes** 查看尚未结束的操作。耗时的 Clone、Fetch、Push、比较、更新和文件读取可能在这里出现；完成后从队列移除，这里不保留历史记录。

- 任务详情显示阶段消息、进度或 **Running…**；同一仓库的写操作也可能正在等待其他操作结束。
- 有 **Cancel** 时可请求取消；队列显示 **正在取消…**，按钮暂时禁用，直到确认任务结束才移除。关闭并重开队列仍会保留取消中状态。
- 取消请求失败时显示错误并允许重试；取消不等于自动回滚整个操作。任务失败后查看对应错误提示及 Console，检查实际状态后再决定重试。

同一仓库写操作可能串行等待。重复点击按钮不会加快进度，切换标签也不会取消操作。创建标签、提交等分阶段操作可能已经完成本地写入，只在远程阶段失败；对应恢复方法见各功能章节。
