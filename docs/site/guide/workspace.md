# 工作区与界面导航

## 主界面的五个区域

![gitx 主工作区：Commit、Diff 与 Log](/screenshots/commit-diff-zh.png)

| 区域 | 用途 |
| --- | --- |
| 顶部工具栏 | 项目切换、分支、VCS 菜单、更新项目、提交、推送、历史、主题、查找动作和设置 |
| 左侧竖条 | **Commit** 管理修改；**File** 浏览整个目录；**Git** 打开或收起底部工具窗 |
| 左侧面板 | 显示当前 Commit 或 File 内容，可拖动分隔线调整宽度 |
| 中间编辑区 | 文件、Diff、比较、历史修订或冲突合并标签 |
| 底部工具窗与状态栏 | Log、Update Info、Stashes & Shelves、Console、Terminal，以及按需打开的 Worktrees；状态栏查看后台任务与当前分支 |

点击已展开的工具窗入口可收起面板。用分隔线调整大小；Git 面板右上角可最大化，再次点击恢复。

## 打开与切换项目

按 `Ctrl+O` 打开文件夹，也可以点击顶部项目名旁的 **Recent projects** 选择最近项目。打开新项目时，根据提示选择当前窗口或新窗口。最近项目记录只是入口，移除记录不会删除目录。

**工作区文件夹**与**活动 Git 仓库**可能不同：工作区可能是仓库子目录，也可能包含多个仓库。File 显示工作区目录，Commit/Log/分支面向当前活动仓库。多仓库操作前先核对顶部和状态栏的仓库/分支。见[多仓库](./worktrees)。

## 查找动作

1. 按 `Ctrl+Shift+A`，或点击顶部搜索图标，打开 **Find Action**。
2. 输入操作名，如 `Stash`、`Worktree`、`Settings` 或中文名称。
3. 用上下方向键选择，按 Enter 执行；Esc 关闭。

这是后文提到的“通过查找动作打开”的统一入口。需要仓库、文件或提交选择的命令会随上下文启用；在输入对话框里先关闭对话框再操作。未显示默认快捷键的功能仍可从菜单或查找动作使用。

## 编辑器标签

点击标签切换内容。右键标签可以关闭当前、其他、右侧或全部标签；“右侧”按当前可见顺序计算。尚未保存或尚未应用的编辑会阻止直接丢弃，按提示保存或确认后再切换/关闭。不要把关闭 Diff 当作回退文件；Diff 只是视图。

普通文件切到其他文件、工作区、历史或差异页面再返回时，会保留光标/选区、滚动位置、撤销/重做及文件内搜索条件。保存不会清空本次标签的撤销记录，撤销后若与已保存内容不同，会重新标为未保存。关闭标签后再打开会重新读取文件；这些编辑状态只属于当前打开的标签，不跨关闭或应用重启保留。搜索结果定位只跳转一次，之后切回标签会保留你后来移动的位置。

## Commit 工具窗布局

通过查找动作搜索 **Commit Tool Window**，或 **Settings → Git → Commit tool window mode**，选择 **Docked / Window / Float**。这些是应用内工具窗的呈现方式；Float 会覆盖工作区的一部分。切到 File 后，返回 Commit 可继续原来的提交草稿。

**Toggle Commit Controls** 可显示或隐藏提交说明区域；按 `Ctrl+K` 会回到提交界面。若看不到输入框，先检查这一设置。

## 刷新与后台操作

文件变化通常会自动刷新；必要时按 `Ctrl+R`。刷新本地状态不同于 **Fetch**：前者检查磁盘，后者访问远程仓库。长任务在状态栏 **Background processes** 中显示进度；切换视图不等于取消任务。任务失败时查看[Console 与任务](./terminal)。
