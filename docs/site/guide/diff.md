# 差异与部分暂存

## 打开并读懂 Diff

在 Changes 中双击文件，或选中后按 `Ctrl+D`。先看标签上方的版本名称：

| 比较方向 | 含义 |
| --- | --- |
| HEAD → Staged | 上一次提交与暂存区，表示已经准备提交的内容 |
| Staged → Local | 暂存区与磁盘文件，表示尚未暂存的内容 |
| 修订 → 修订 / Local | 两次提交或历史与本地之间的比较，通常用于阅读 |

![Staged 到 Local 的双栏差异](/screenshots/commit-diff-zh.png)

红色表示删除，绿色表示新增。左侧行号属于旧版本，右侧行号属于新版本；两者可能不同。重命名会使用各版本对应的路径。

## 阅读控制

工具栏提供 **Unified / Side by side** 切换、**Whitespace** 空白处理、折叠/展开未更改内容。空白忽略只影响比较显示，不会替你格式化文件或保存变更。若提示换行符不同，请检查 LF/CRLF，即使可见文字一样也可能存在差异。

Diff 是只读视图。想直接修改磁盘文件，在 Changes 按 **F4**，或到 File 双击文件，编辑后保存。比较标签不会把历史内容自动写回当前文件。

## 按块操作

每个修改块的右栏边缘（Unified 模式为该块边缘）提供操作按钮，悬停或用 Tab 聚焦可查看动作名称：

| 比较方向 | 按钮 | 结果 |
| --- | --- | --- |
| Staged → Local | **+ 暂存此块** | 只将此块放入暂存区，其他修改保留在工作区 |
| HEAD → Staged | **− 取消暂存此块** | 将此块从暂存区移出，磁盘文件保持 |
| Staged → Local | **↶ 回退此块** | 确认后丢弃此块未暂存修改，保留其他块及已暂存内容 |

双栏/Unified、折叠/展开未更改内容均支持这些按钮，包括纯删除块。回退整个新增文件的唯一块会删除该工作区文件；回退已删除文件的块会恢复文件。回退无法撤销，请核对路径和块号。

操作期间按钮禁用，任务队列显示正在执行的动作。完成后会刷新 Changes 和当前 Diff；若写入已完成但刷新失败，会明确提示，可点击 **刷新并重新核对**，无需重复写入。后台或外部编辑导致预览变化时，操作会拒绝旧块，请刷新后重新检查。

这些按钮只用于普通文本文件的上述两种比较。忽略空白模式需先改为显示所有空白变化；历史比较、重命名比较、Combined Diff、二进制或过大内容不提供逐块写操作。按块分配 Changelist 仍未提供。网页演示不能执行真实 Git 块操作，请使用桌面应用。

## 按行暂存

当前 **Stage selected lines** 使用行号输入框：

1. 打开 **Staged → Local** 的普通文本 Diff。
2. 点击 **Stage selected lines**。
3. 输入右侧新版本中实际新增/修改行的行号，例如 `4, 7` 或 `4 7`，用逗号或空格分隔。
4. 确认并检查暂存后的 Diff。它不会把你用鼠标选中的任意文字直接当作补丁。

只接受当前差异中的可暂存新行；`4-7` 范围写法、未变化行、旧版本删除行号不适用。需要处理纯删除或完整替换时，使用上面的逐块按钮。

::: tip 确认最终提交内容
部分暂存后启用 Staging 模式，并查看 **HEAD → Staged**。如果重新选择整文件提交，可能把原本打算保留的其他修改也纳入。
:::

## 多文件比较与大文件

在 Log 或比较界面选择文件可逐一打开 Diff；**Combined Diff** 把比较中的多个文件放在同一视图阅读，仍需查看各文件的版本方向。加载失败时使用 Retry。二进制或超出显示限制的内容会提示无法文本比较，应改用合适的外部工具；这不表示两个文件完全相同。
