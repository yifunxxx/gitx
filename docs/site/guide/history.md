# 日志、历史与比较

## 浏览 Log

点击顶部 **Show Log** 或底部 **Log**。图线表示父子关系，文本显示说明、作者、日期和分支/标签。选中一行，右侧显示完整提交说明、父提交及 Changed Files；点击文件查看这一提交的差异。

使用 **转到哈希 / 分支 / 标签** 时，解析目标和读取所在历史窗口会进入任务队列。找到后立即选中并滚动到目标，详情继续独立加载；详情慢或失败不会阻止定位，失败时可在详情区重试。方向左键跳到未加载的父提交同样适用。

读取提交期间，右侧和任务队列显示正在读取的修订。读取失败时，详情区保留错误及 **重试** 按钮；详情重试不会取消多选或改变 Shift 连选起点。成功读取的空提交会明确显示没有文件变更，避免与等待或失败混淆。

![示例仓库的提交图和分支](/screenshots/history-en.jpg)

用 Ctrl 多选或 Shift 连选提交。右键可复制修订号、新建分支/标签、检出、比较、Cherry-pick 或执行[历史整理](./rewrite)。写操作随选中数量和仓库状态启用。

## 筛选和定位

1. 在筛选栏输入提交说明、作者、分支/修订范围（如 `main..feature/search`）或文件路径。
2. 选择日期条件，点击 **Apply** 或在筛选框按 Enter；**Clear** 清除过滤。
3. 展开更多选项可切换日期/拓扑排序、First parent、隐藏 Merge 等显示条件。
4. 在 **Go to Hash / Branch / Tag** 输入修订，按 Enter 定位。目标不在已加载窗口中时会加载相关历史；需要回到当前头部时使用返回最新记录的入口。

输入法候选确认不会应用筛选或跳转，完成文字输入后再按一次 Enter。长按 Enter 或同时按住 Ctrl、Alt、Shift、Meta 不会重复发起这些操作。提交行支持上下方向键连续移动及 Shift 连选，普通 Enter 打开该提交的差异。

滚动到历史边界会加载更多记录，也可使用界面中的 Load more / 较新记录入口。分支很多时图线区域可横向查看；图形列不是额外的提交列表。

首次读取或筛选失败时，筛选栏仍保留在原位，可直接修改条件、清除筛选或点击错误区的 **重试**。失败区域不会显示旧提交作为当前结果；重试使用当前输入条件，并将焦点放回提交说明筛选框。

设置 **Log list mode** 可选择平铺或分支树形显示。**Rebuild index** 重建本地日志索引，便于筛选；它不会创建提交或改写 Git 历史。筛选为空时先 Clear，再检查分支范围。

提交历史读取期间会显示“正在加载提交历史…”并在左下角任务队列登记当前仓库；完成后任务消失，真正的空结果才显示“没有匹配”。重建期间按钮显示“重建中…”，左下角任务队列显示该仓库的索引任务。可以继续筛选和浏览记录；切走再返回同一仓库也不会重复重建。完成后更新索引状态，失败时恢复按钮，可查看错误后重试。

## 比较两次提交或与本地比较

- 选中两次提交，右键比较，查看变更文件并打开 Diff。
- 选中一次提交，选择 **Compare with Local**，比较该修订与当前工作区。
- 需要一屏浏览多个文件时使用 Combined Diff；需要可编辑文件时从 File 打开本地文本。

比较方向决定新增/删除含义；切换左右或本地目标后重新读标签。比较本身不写入文件。

## 单文件历史

1. 在 Changes、File 或日志更改文件菜单选择 **History / Show History**。
2. 在历史列表选择提交，查看该次对文件的修改；按需打开 **All branches**。
3. 通过 **Compare with Local** 对照现在的文件。
4. 用加载更多继续查看旧记录；加载失败先 Retry。

历史会考虑重命名前的路径。首次提交、删除文件或合并提交的差异可能与普通“两侧都有文件”的场景不同，不应把空侧视作加载失败。

## 浏览指定修订的仓库

在 Log 选中提交，使用 **Show Repository at Revision**（`Ctrl+Shift+O`）。进入目录，选择文件查看当时的文本；**Up** 回上级，**Show History** 查看所选文件历史，**Compare with Local** 与当前文件对照。

点击 **Restore** 会把选择的历史文件恢复到工作区和暂存区，确认前核对修订、路径和可能被覆盖的本地内容。恢复之后需要自行检查并提交。浏览历史和恢复历史是两种不同操作。

相关文件有未保存草稿时，先保存或关闭编辑标签；有冲突合并编辑器时，先完成或关闭它。恢复不会丢弃这些草稿。文件加载、保存或其他文件操作尚未结束时请稍后重试。恢复期间相关编辑器临时只读并显示“正在恢复文件…”，完成后关闭已恢复文件的旧内容标签，重新打开会读取磁盘版本；失败则保留文件标签和正文，处理错误原因后可以重试。

二进制、过大内容、无效修订或不可读取对象会有提示。使用 Retry 或重新选中修订，不要把失败提示当成“文件内容为空”。
