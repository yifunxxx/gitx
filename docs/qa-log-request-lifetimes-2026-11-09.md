- 提交列表、提交详情、索引状态分别跟踪请求序号，同时核对仓库导航 token。
- 离开仓库清空行、详情和选择；选择新提交立即清空旧详情。取消多选中的焦点条目时改为剩余选择。

- 集成版本的定位/向前分页也补齐同一导航 token 检查，保留其既有功能。
