# QA114 Log 树模式切换仓库

## 现象与基线

Log的平铺图文快照已经按仓库同步清空，树形提交行却只在下一次动画帧重建。切换仓库后，在新历史等待或已返回但布局尚未执行时，旧仓库的提交仍可见且可操作；点击旧tip会调用`path=B, sha=tip`，把旧行交给新仓库。

开始基线d30880c包含masterfdc5156（0.1.49），同步首次TLS失败、重试成功。中途按用户优先级完成搜索功能QA115；三份QA114工作通过命名stash保留并完整恢复。恢复后两次schannel握手失败，单次OpenSSL代理fetch成功，确认HEAD/交付5748edc及masterfdc5156均已整合后继续，全程主线程。

## 修改

- 仓库路径或身份变化时，同步清空树形呈现并取消旧树布局帧，防止旧提交或分支标题在新仓库继续操作。
- 树布局依赖补上仓库身份，即使路径相同也会重新安排当前呈现。
- 仓库变化时释放失效的布局等待；定位流程保留原有仓库归属检查。
- 同仓库普通后台刷新仍保留原呈现到新帧完成，不把刷新过程变为空列表；树模式仍跳过隐藏图线计算。
