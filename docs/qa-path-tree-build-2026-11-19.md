# QA-034：路径树同步构建开销复查

2026-11-19，基线为远端 `ce630fd`（0.1.40）。Changes、Log 和 Compare 共用 `buildPathTree`；大批文件列表更新时，它在主线程同步执行。本项是 QA-034 的性能改进，不将函数耗时当作原生滚轮时延。

原实现给每个文件叶子也分配 Map，随后先排序并生成全树 `order`，再借助 `childrenOf` 生成输出并排序。修改为仅下降到目录时分配 Map，使用待处理目录栈直接填充输出，每层仅排序一次。保持目录优先、原始路径和重命名元数据、可选择目录叶子、深路径非递归处理，以及 Unicode 等价字符名字的原有稳定次序。

## 对照测量

Node 24.22.1，同进程加载远端基线与修改后的实际函数，各预热 3 次后交替执行 15 对；每次计时前显式 GC。输入采用固定种子打乱，计时仅含建树，不含数据生成、完整结果比较、组件渲染或原生呈现。各场景完整输出 JSON 均相等；另有 300 组打乱的路径边界语料比较相等。

| 场景 | 基线中位数 | 修改后中位数 |
| --- | ---: | ---: |
| 200 个文件 | 0.90 ms | 0.41 ms |
| 20,000 个嵌套路径文件 | 59.99 ms | 42.37 ms |
| 50,000 个平级文件 | 167.83 ms | 137.52 ms |
| 6,000 个独立目录，每个含子目录和文件 | 38.04 ms | 26.33 ms |

在未打乱的同一组 20,000 个嵌套路径输入上，插桩记录 Map 构造次数从 20,403 降为 402，名称比较次数从 109,490 降为 65,453。插桩另行运行，不混入时间测量。脚本、基线源码、原始样本和计数位于 `E:/IDEAproject/gitx/test-results/path-tree-{ab,work}-20261119.{mjs,json}` 和 `path-tree-baseline-20261119.ts`。
