# QA-034：路径树同步构建开销复查

2026-11-19，基线为远端 `ce630fd`（0.1.40）。Changes、Log 和 Compare 共用 `buildPathTree`；大批文件列表更新时，它在主线程同步执行。本项是 QA-034 的性能改进，不将函数耗时当作原生滚轮时延。

原实现给每个文件叶子也分配 Map，随后先排序并生成全树 `order`，再借助 `childrenOf` 生成输出并排序。修改为仅下降到目录时分配 Map，使用待处理目录栈直接填充输出，每层仅排序一次。保持目录优先、原始路径和重命名元数据、可选择目录叶子、深路径非递归处理，以及 Unicode 等价字符名字的原有稳定次序。
