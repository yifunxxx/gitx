# QA-028 文件保存期间的草稿保护

## 发现和修改

检查 0.1.37 文件编辑功能时发现：编辑器在保存期间仍允许输入，但 Store 因 `saving` 丢弃文档更新；后端刷新行标记后重新创建编辑器，会清除保存期间的输入、选区和撤销记录。失败后再次保存也可能仍发送旧草稿。

三个定向回归在修改前分别确认上述问题。修复后保存请求固定原内容，等待期间的输入继续同步；成功只把已写入的内容作为基线，新输入仍为 dirty。行标记仅在草稿仍匹配保存内容时刷新，通过 Compartment 更新装饰而不销毁编辑器。写入失败保留最新草稿；重复保存仍被拦截。
